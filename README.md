# Desafios VB.NET

Projeto desenvolvido para prática e demonstração de conhecimentos
em desenvolvimento VB.NET, orientação a objetos e regras de negócio.

## Tecnologias

- VB.NET
- .NET
- Visual Studio
- System.Text.Json
- LINQ

## Desafios

### 01 - Comissão de Vendedores

Leitura de dados em JSON e cálculo de comissão conforme regras
de negócio.

- Desserialização de JSON
- DTOs
- Dictionary
- Decimal
- LINQ
- Service Layer
- Validação

### 02 - Movimentação de Estoque

Controle de entrada e saída de produtos.

- DTOs
- Regras de negócio
- Validação
- Controle de estoque
- Tratamento de exceções

### 03 - Cálculo de Juros

Cálculo de juros por atraso utilizando data de vencimento.

- DateTime
- Cálculo de diferença entre datas
- Decimal
- Regras de negócio
- Validação
